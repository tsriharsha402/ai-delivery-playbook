# Contributing

Improvements from real use are the most valuable contributions: a question a template
failed to ask, a checklist item that would have caught an incident, a section nobody
ever fills in.

- Keep templates short. Every added line is a line someone has to fill in; remove one
  when you add one if you can.
- Explain *why* in the pull request, ideally with the situation that exposed the gap.
- Run `python scripts/check_links.py` before opening a pull request.
